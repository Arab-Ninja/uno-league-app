# Démarches : les courriels

Un fichier par courriel, en texte brut : tout sélectionner, copier, coller.
La première ligne est l'objet (à mettre dans le champ « Objet »), le reste
est le corps, signature comprise. Joindre le dossier dans la langue du
courriel : `UNO-League-dossier.pdf`, `-nl.pdf` ou `-en.pdf`.

| Fichier | À qui | Remarque |
|---|---|---|
| `1-organismes-publics` / `1-overheden` | COCOF, administrations du sport, communes ; Sport Vlaanderen, VGC | demande si un soutien est possible avant de constituer l'ASBL |
| `2a-federations` / `2a-federaties` | ACFF ; Voetbal Vlaanderen | plutôt que l'Union belge au niveau national |
| `2b-centres-partenariat-ligue` / `2b-centra-…` | centres five, salles | créneaux et partenariat ligue |
| `2c-centres-uno-vision-pilote` / `2c-centra-…` / `en/2c-…` | centres five | UNO Vision : devenir centre pilote |
| `2d-confirmation-cinq-centres` / `2d-bevestiging-centra` | les cinq centres d'accord à l'oral le 14 octobre | leur réponse « je confirme » est l'accord écrit que demande le RGPD |
| `3-marques` / `3-merken` / `en/3-brands` | marques | sponsoring, produits dans la boutique |
| `4-innovation-innoviris` | Innoviris | seulement si une structure bruxelloise porte le projet |
| `4-innovatie-vlaio` | VLAIO | le siège est en Flandre : c'est l'interlocuteur pour UNO Vision |
| `relance` / `herinnering` | tous, 8 à 10 jours sans réponse | en **réponse** au premier courriel : l'objet se remplit tout seul |

Un courriel par organisation, envoyé depuis contact@unoleague.be, sans copie
groupée. Personnaliser « Bonjour, » ou « Madame, Monsieur, » quand le nom du
contact est connu.
